# The Regulatory Waterbed

**Why Mandatory Disclosure Moves Information Asymmetry Instead of Removing It**

Hakvin Vosteen · Universität Bremen · 2026

[![Paper](https://img.shields.io/badge/SSRN-Working%20Paper-blue)](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6415318)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## What this paper does

Mandatory disclosure regulation (like the EU' CSRD) is designed to reduce information asymmetry. We show it works like a waterbed: push down in one place, the problem surfaces somewhere else.

We formalize this with a **graph-Laplacian diffusion model** where information asymmetry is a field on an institutional graph, regulation is a source term, and migration follows the graph's eigenmodes with empirically measurable relaxation times.

**Key results:**
- Three migration channels with relaxation times spanning 13:1 (Processing: ~1yr, Supply Chain: ~11yr, Audit: ~14yr)
- ESG rating disagreement growing faster than disclosure (Welch t = -4.1, p = 0.008)
- System stuckness increased 33% post-CSRD (KPMG: disclosure at 77%, audit readiness at 29%)
- Reconciles contradictory findings of Krueger et al. (2024, JAR) and Boulton (2024, EFM)

## Reproducing the results

```bash
# Install dependencies
pip install -r requirements.txt

# Step 1: Fetch data from OpenAlex (requires internet)
python src/01_openalex_query.py

# Step 2: Generate all figures
python src/02_figures.py
python src/03_calibration.py
python src/04_arrival_times.py

# Step 3: Run statistical tests
python src/05_statistics.py

# Step 4: Compile paper (requires LaTeX)
cd paper && pdflatex waterbed_v2.tex && pdflatex waterbed_v2.tex
```
